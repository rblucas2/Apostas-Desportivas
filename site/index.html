Sincronização telemóvel ↔ PC

O boletim é guardado num Gist privado da tua conta GitHub. Usa o mesmo token nos dois dispositivos e o boletim fica igual em ambos.

  1. Em GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic), cria um token só com a permissão gist.
  2. Cola-o abaixo no telemóvel e no PC.

Sobre os dados

  • Classificações, resultados e calendário: API pública da ESPN, atualizada a cada 6 horas.
  • Cotas 1X2: Betclic França, via The Odds API. Podem diferir ligeiramente da Betclic.pt e não são garantidas no momento da aposta. A Betano não está nessa API: introduz a cota manualmente no boletim. A Eerste Divisie e a Championship escocesa não têm cotas.
  • As séries de derrotas contam apenas jogos do campeonato.

Jogo responsável: aposta apenas o que podes perder. Linha de apoio SICAD: 1414.
